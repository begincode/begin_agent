# 第23步：共享数据库 Worker 心跳与运行告警

日期：2026-11-06。用户授权连续完善第二十至二十五步，范围见[计划](../specs/feature-steps-20-25.md)。

## 功能与迁移

新增 worker_pulse，Worker 每十秒使用数据库时间上报随机实例编码，退出时标记停止；API 聚合 45 秒有效窗口内活跃数、过期数，不暴露主机名或 PID。覆盖同一数据库的多主机进程，保留原本机 PID 就绪检查。心跳证明仍上报，不证明模型、工具或领取权限就绪。

系统状态页新增运行告警：有效心跳缺失、任务租约过期/缺失、等待五分钟、最近一天失败。队列仍额外要求 tasks.read。告警按样本指纹确认，确认只属于当前账号/租户，不修复故障、不抑制其他账号；样本变化重新提示。确认接口重新计算样本，过期返回 409；停用租户禁止确认。没有外部通知或自动任务重试。

迁移 20261106_08 新增心跳表和租户 FORCE RLS 的 diagnostic_acknowledgment。Worker 对心跳表需 SELECT/INSERT/UPDATE；API 对心跳仅 SELECT，对确认表 SELECT/INSERT 及序列 USAGE。真实本地库先停写备份 `.data/local-run/before-step23.dump`，迁移前后 25 张既有表哈希及主密钥一致，再启动 API/Worker。

## 验证

完整后端 265 项、前端 133 项、UI 6 项、类型与生产构建通过。真实迁移上的非特权 RLS、两个实例聚合、停止/过期、确认幂等和租户隔离、样本变化重开均通过。

独立 Chromium 配合独立真实 Worker：启动看到有效数据库心跳；退出后制造隔离等待样本，出现两类告警；确认持久化、只读账号直接确认 403；取消样本后重启 Worker，告警消失。模型/MCP 调用零。健康与告警共 12 组六视口截图/尺寸，控件符合规范、无外层溢出。证据 output/playwright/implementation-step-23：完整日志、interactions、geometry、截图、迁移备份哈希和 restart-check。

本轮进程均在本机，跨主机语义由共享数据库和实例聚合测试验证，未在两台真实主机部署。告警是手动采样观察，未接短信、邮件或 Prometheus；确认记录及历史心跳暂不自动清理。
