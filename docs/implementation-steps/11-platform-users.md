# 第十一步 平台用户目录与独立详情

状态：已完成。对应平台用户列表、创建和用户详情原型。

## 实现

- 用户目录支持账号/姓名/编码/历史标识的大小写不敏感搜索，`%`、`_` 按字面量处理；状态和平台身份组合筛选，默认 50、最大 100 条的稳定分页，保留数组响应格式。
- 新增 `GET /api/v1/users/{user_code}`。目录与详情均在 API 校验平台管理员身份，普通账号不能读取；不返回密码哈希或数据库内部 ID。
- 独立 `#/users/new` 和 `#/users/{user_code}`，可创建账号、刷新直达详情、编辑名称/状态/平台身份、重置密码；历史开发身份只读，不假装具备内置登录凭据。
- 复用原创建/修改/重置接口，保留当前账号不可停用、最后平台管理员保护、停用与重置撤销会话。本人修改同步身份与顶栏，降权后退出平台管理页，本人重置后需重新登录。
- 账号属于平台，租户停用不妨碍平台管理员管理账号；加入租户及授予角色仍通过成员管理。没有新增数据库结构。
- 主要代码：`app/services/users.py`、`app/api/workspace.py`、`UsersWorkspace.vue`、`AdminView.vue`、`platform.css`。

## 边界

不新增账号删除、自助注册、邮箱找回或跨租户成员批量迁移。目录不持久化筛选条件；从详情回到目录默认重新查询。新账号默认没有租户访问权，需通过成员管理加入。所有业务写入在隔离库，不修改实际用户或模型配置。
