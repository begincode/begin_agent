# Begin Agent 侧栏目录折叠与滚动体验优化

随着工作空间、能力资源和管理入口增加，侧栏需要容纳更多菜单。用户希望收起暂时不用的目录，同时避免浅色原生滚动条破坏深色导航的整体观感。

这次调整为三个导航分组增加独立折叠按钮，并把左侧滚动条收敛为深色细滑块。分组标题保留清晰的箭头方向，鼠标和键盘都可以操作。

## 折叠状态需要可恢复

用户收起一组目录后，状态保存在当前浏览器，刷新页面仍然保留。存储内容无效时恢复默认展开，避免损坏的偏好影响工作台加载。

切换到另一个菜单入口时，如果目标分组处于折叠状态，导航会展开该分组，让当前页面入口重新可见。分组按钮同时提供展开状态和关联内容标识，支持屏幕阅读器理解操作。

## 窄屏继续保留入口

整体侧栏收起后只显示图标，手机布局也隐藏分组标题。如果继续沿用分组折叠，用户就可能既看不到菜单，也找不到展开按钮。

因此图标栏和手机布局会显示全部已授权图标，回到宽侧栏后再应用原来的分组偏好。权限筛选仍然生效，折叠只改变展示范围。

## 让滚动条融入深色导航

左侧滚动条采用 6px 宽圆角滑块和透明轨道，去掉明显的白色轨道。悬停导航或通过键盘聚焦时，滑块颜色增强，便于发现当前滚动位置；其他浏览器保留细滚动条后备样式。

滚动仍发生在导航内部，底部的账号与整体收起按钮保持独立。新增分组按钮沿用统一的 40px 高度和 8px 圆角。

## 验证结果

本次前端 53 项功能测试、6 项 UI 规则测试以及类型检查、生产构建通过。浏览器实际验证了键盘折叠、状态恢复、图标栏入口和底部菜单访问，并对三种状态各检查六种视口，共保留 18 组截图与几何记录。

本次验证采用已授权的独立 Chromium；Firefox 的后备样式未单独实测。具体实现与证据见[验收记录](../../specs/feature-sidebar-navigation.md)。
