# 刷新以后，向导里的编辑应该如何保留

创建幂等解决了“创建了几个 Agent”，用户还会关心“我刚写的提示词去哪了”。第二十步把这两份状态分开：创建请求身份保持稳定，未保存编辑另有一份有期限的标签页草稿。

保存内容采用白名单，只包含表单字段和资源编码，不复制模型配置对象或密钥。界面告诉用户提示词也会保存在本标签页；24 小时与 128KiB 限制让恢复记录有明确边界。

刷新以后先询问继续还是放弃，避免把恢复理解成自动保存。继续可以找回模型、长提示词和原步骤；如果创建回执曾经丢失，再次提交仍使用原来的键。放弃完整编辑也不会丢掉未知结果的创建身份。

自动检查发现初始化顺序问题，浏览器又暴露默认模型自动生成空草稿，均修正后复验。最终后端 246 项、前端 128 项及 UI 6 项通过，12 组视口记录覆盖恢复面板和完整向导。恢复让编辑可继续，提交仍须经过原有权限和并发条件。
