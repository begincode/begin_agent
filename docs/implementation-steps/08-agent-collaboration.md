# 第八步 SubAgent 协作配置

状态：已完成。补齐协作原型与 AgentRelation 设计中的调用方式、单次超时和启停配置。

## 实现

- `GET /api/v1/agents/{code}/relations` 同时返回启用和停用关系，附子 Agent 名称、状态及当前发布版本。上限与发布读取保持为 1000；按时间与关系编码排序。
- 新增 `PATCH /api/v1/agents/{code}/relations/{relation_code}`，支持调用方式、1–1800 秒单次超时与启用状态；未提交字段保留原值，不能替换目标子 Agent。新增、更新、删除共用租户关系图事务锁。
- 新增拒绝重复、自调用、未启用/未发布子 Agent。停用关系可以编辑和重新启用；重新启用重新检查有效关系图的循环依赖，不能因停用绕过检查。跨租户和主 Agent 不匹配均拒绝。
- 独立协作面板支持新增、单关系编辑、保存、取消、启停和移除，保留只读视图与版本入口。保存明确提示重新发布后生效，当前子版本展示不冒充历史任务使用的子版本。
- Agent 候选目录分批补齐，列表按时间和编码稳定分页；已有关系、停用与未发布 Agent 不进入新增候选。
- 关系修改只影响下一次发布的快照，已有 AgentVersion、任务与子版本不改写。子 Agent 自身停用和资源授权撤销的运行时规则仍保留。
- 主要代码：`app/domain/platform.py`、`app/services/platform.py`、`app/api/platform.py`、`CollaborationPanel.vue`、`AgentEditor.vue`、`PlatformApp.vue`。

## 边界

关系启停决定下次发布的依赖，不是对历史版本即时撤销子调用；需要立即阻止某个 Agent 执行时仍使用 Agent 停用机制。当前不新增关系修改的并发修订号，多个编辑者最后提交的字段值生效；图结构安全由事务锁保证。目录仍按批加载，超大目录的搜索和缓存待后续评估。前端构建保留单主包，当前 minified 约 501kB，构建有体积提示，未调整或屏蔽阈值。
