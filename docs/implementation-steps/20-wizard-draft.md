# 第20步：向导完整草稿恢复

日期：2026-11-06。用户授权连续完善第二十至二十五步，范围见[计划](../specs/feature-steps-20-25.md)。

## 行为与实现

新增 wizardDraft.ts，按当前账号/租户在 sessionStorage 保存名称、类型、状态、模型编码、提示词、资源编码、模型参数、执行配置及当前步骤。仅白名单字段，最多 128KiB、24 小时；模型 API Key 等未知字段不会保存。提示词可能包含用户自己的敏感内容，页面明确说明保存范围；关闭标签页后不保证恢复。

刷新后先显示恢复选择，不自动提交。继续编辑还原所有字段；放弃仅清除完整本地草稿，不丢弃未确认创建的幂等标识。丢响应后恢复完整草稿再保存，仍重用第十九步原请求和初始 ETag。成功保存或选择仅找回原 Agent 后清理完整草稿。存储失败显示提示，跨身份异步返回不继续写入。空默认表单不生成恢复记录。
