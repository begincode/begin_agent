# 第三步：资源管理闭环

状态：已完成。

## 验收标准

- 工具可启用/停用、修改分组；停用工具不能用于新版本发布或实际工具执行，旧版本记录不改写。
- 工具列表支持按组、状态、名称查询；工具/MCP/Skill 资源管理支持服务端分页，查看详情不依赖当前列表第一页。
- Agent 目录分批补全资源元数据，避免只加载第一页；跨租户详情返回 404，密钥不回显。
- MCP 凭据变更使旧工具发现结果失效，需重新检测，不把保存当作检测通过。

## 本步结果

- 工具创建/编辑支持 status，停用后不能进入新版本，也不能通过旧版本实际执行；已有版本与工具绑定保持原记录。
- 工具/MCP/Skill 列表支持服务端 search/status/limit/offset，工具增加精确分组筛选与分组目录。
- 模型、工具、MCP、Skill 详情按实体编码直接请求服务端，跨租户返回 404，不再从当前第一页查找详情。响应继续排除密钥与密文。
- 工作台分批补齐工具/MCP/Skill 资源元数据，重复分页会报错而非无限循环；Agent 不会漏掉第一页之后的资源。停用的已有绑定仍可取消选择，未绑定的停用项不可新选。
- MCP Token 修改/清除使工具目录与检测时间失效，需要重新检测；不影响已有版本快照。
- 主要代码：`app/services/resources.py`、`app/api/platform.py`、`app/api/workspace.py`、`app/api/chat.py`、`PlatformApp.vue`、`ResourceEditor.vue`、`WorkspacePage.vue`、`AgentEditor.vue`。
