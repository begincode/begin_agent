# 第十三步 任务实时输出与恢复

状态：已完成。对应任务执行期间的正文、思考过程和阶段更新，补齐此前只在执行结束后读取结果的限制。

## 实现

- 默认 Runtime 使用既有模型网关的流式接口，读取正文/思考片段及完整结束响应。工具和子 Agent 继续使用已有版本、预算、超时和权限约束，不在流出错后自动重放模型请求。仅实现 generate 的旧注入网关保留兼容。
- 复用可更新的 `AgentRun.output.live` 保存累积预览、模型调用序号和当前阶段。每次写入经过 `TaskQueue.owned` 的有效租约、状态、取消检查；不修改不可变的 RunStep/RunMessage，不新增表或迁移。
- 正文与思考各限制 65536 字符。片段按约 150ms/1024 字符合并写入，上游等待期间也会刷新已接收内容；没有新内容时不反复写入。已知凭据跨片段时保留未完成前缀再脱敏，截断边界也不释放凭据前缀。
- 新增 `GET /api/v1/tasks/{code}/stream`。SSE 每约 300ms 从短数据库会话读取当前轮次/尝试的最新快照，内容变化才推送，空闲时心跳；20 秒轮换连接。快照替换而非增量拼接，重连直接读取最新持久化状态，不要求逐 Token 事件重放。
- 任务读取使用当前租户与 `tasks.read`；子运行阶段另需 `runs.read`。连接期间约每 1.5 秒重新检查会话和权限，撤权/失效发送访问错误后关闭。任务详情的轮询入口同步限制运行记录，避免降级路径绕过权限。
- 任务页显示实时草稿、折叠思考和执行阶段，保留正常连接、重连与轮询降级提示。离开页面取消读取与计时器，不取消后台任务；断网后恢复不会重复拼接，阅读历史时不强制拉回底部。
- 流连接结束不等于任务成功。任务达到终态后重新读取正式 Task/TaskTurn 输出；只有成功结果进入上下文和产物。失败、取消、超时保留有限的“中断草稿 · 非最终结果”。任务历史返回各轮最近根 Run 的草稿，进入新轮次或刷新后仍可查看以前的中断内容。
- 主要代码：`app/runtime/progress.py`、`app/runtime/agent.py`、`app/repositories/task_queue.py`、`app/services/task_stream.py`、平台/工作区路由、`taskLive.ts`、`TaskWorkspace.vue`、`ExecutionPanel.vue` 与共享样式。

## 边界

这是合并片段后的实时快照，不是供应商 Token 一一对应的事件存档，也没有宣称模型逐 Token 延迟 SLA。每轮只展示最近尝试的根 Run 草稿；旧尝试的 Run 记录仍保留。预览截断后失败任务无法还原未保存的其余文本；成功正文与产物继续使用原有完整结果限制。

当前使用数据库短轮询分发，未做大量并发观看者压测、缓存或独立事件总线。客户端断网时保留可见草稿并标注恢复状态；任务执行依然受服务端预算、租约和整体超时限制。390×360 是低高度检查，不冒充真机软键盘测试。

无数据库迁移，所有业务写入只在隔离库。原账号、模型配置、主密钥及实际业务数据保留；不恢复 SSO，不登记或部署远程 PMS，不调用付费供应商。
