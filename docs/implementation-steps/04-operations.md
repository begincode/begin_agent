# 第四步：运营概览与审计

状态：已完成。

## 验收标准

- 概览支持 7/30 天统计，按北京时间的创建日期归集，显示每日任务、成功率、运行次数、平均已结束运行耗时及已上报模型 Token。
- 模型统计基于不可变版本与实际模型步骤，不引入价格、估算费用或计费。未返回用量时显示未知/未上报，不填假零。
- 任务读取和运行读取分别决定可见统计，不能通过概览越过角色/租户权限。
- 审计按操作者、日期和文本检索并分页，显示可读操作名称；原始路径/状态仍可查，不包含密码或密钥。

## 本步结果

- 概览新增近期统计，界面支持 7/30 天，API 支持 1–30 天；按北京时间日历日与任务/Run 创建时间归集。每日任务按当前状态统计，多轮对话不计为新任务，Run/模型调用单独累计。
- 展示任务数、成功率（不含取消）、Run 数、已结束 Run 平均耗时、按不可变模型快照汇总的调用次数和已上报 Token。未上报用量单独计数，部分用量不会显示成完整用量。
- 无任务/运行读取权限时，对应统计字段为空、明细为空，不查询并泄露受限数据。
- 审计新增操作者目录、日期/操作者/路径/资源/姓名查询及 50 条分页；展示操作名称、操作者当前目录名称，详情保留原路径与状态。审计原记录不修改。
- 审计查询按请求顺序保护结果；快速切换筛选时，较早请求的响应不会覆盖当前结果，组件离开后也不写回。
- 主要代码：`app/services/statistics.py`、`app/api/workspace.py`、`OperationsOverview.vue`、`WorkspacePage.vue`、`AdminView.vue`；复用执行用量解析并拒绝负数、非有限数和不安全大整数。

## 限制与后续

本步提供运营计数，不提供计费、费用估算、配额或独立评测系统。统计按请求聚合，尚无缓存；大规模长周期统计需另做性能评估。用户展示名称取当前目录，历史审计的操作者编码与原始路径保持不变。原数据库结构不变，无迁移。
