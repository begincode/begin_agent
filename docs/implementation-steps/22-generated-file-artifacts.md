# 第22步：模型工具生成文件产物

日期：2026-11-06。用户授权连续完善第二十至二十五步，范围见[计划](../specs/feature-steps-20-25.md)。

## 执行语义

新增内置 export_text_file，须先创建工具并授权到 Agent 发布版本；沿用实时权限复验。模型提供文件名及文本，支持 txt/md/csv/json，单个 32KiB、每次根任务最多三个文件（含子 Agent），参数与文件格式均校验。执行器在内存暂存，模型只收到名称、大小和待提交状态；已知供应商凭据先脱敏再编码。

根任务成功后，将私有对象写入既有本地/S3 存储，再把文件元数据与任务/轮次成功状态在同一事务提交。产物来源 GENERATED，关联实际来源 Run；页面区分“执行生成”和“人工上传”，沿用鉴权下载与 SHA256。失败、超时、取消、超过文件数量不提交暂存文件；对象写入失败补偿清理。提交回执不明时先查元数据，数据库不可用则保留对象供核对，不删除可能已提交的文件。数据库与对象存储仍无分布式事务，强制终止可能留下孤儿对象。
