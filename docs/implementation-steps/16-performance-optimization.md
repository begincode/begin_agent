# 第十六步 性能优化与可复查基准

日期：2026-11-06。状态：已完成本轮范围。规格见 [性能优化需求](../specs/feature-performance-optimization.md)，验收映射见 [验证报告](../specs/feature-performance-optimization-verification.md)。

## 优化内容

### 按页面加载代码与候选目录

平台入口将聊天、任务、Agent 编辑、资源编辑、管理和普通工作区拆为异步页面。概览使用的 WorkspacePage 再把 RunInspector 独立加载，避免概览间接引入 Markdown、DOMPurify 与高亮库。保留原高亮语言、代码复制及渲染安全规则，没有提高 500kB 告警阈值。加载中显示状态，分包失败提供刷新入口，避免空白页面。

共享目录由 workspaceCatalog 按路由确定：概览、普通列表、账号和任务详情不读取编辑器目录；新建任务、协作配置及运行筛选按需读取 Agent；Agent 基本配置按需读取模型、工具、MCP、Skill 和授权目录。目录仍读取后续分页，不会丢掉末页候选。任务详情直接返回单个 Agent 名称，免去为标题拉取全部 Agent。

必要目录读取完成后才挂载页面，避免表单把尚未加载当成没有候选。路由、租户切换及登录失效会清理旧数据、递增读取版本并中止请求；一个目录失败时也取消其他无效分页。页面有独立的目录重试入口，不使用跨租户或跨权限的长期目录缓存。

### 只读取实时输出需要的字段

SSE 快照把 TaskTurn 的最新轮次合入任务查询，只选择任务状态、租约和计数等字段；Run 查询只提取 output.live，不再每 300ms 加载完整 Task 输入/输出和 Run 正式正文。本轮长记录样本含 240kB 任务附加上下文及 500kB Run 正文，实时展示仍只读取必要预览。

每个 FastAPI 应用实例拥有一个 SnapshotCache，键包含数据库工厂、租户、任务和 runs.read 查看能力。正在执行的相同读取由多个观看者共同等待；非终态快照最多复用 250ms，初次连接仍直接读取，终态和异常不缓存。缓存最多 64 条，每条编码结果最多 512KiB；超限读取正常继续但不保留缓存。没有后台轮询任务，应用关闭时取消共享读取并清空状态，单个观看者断开不会取消其他人的读取。

每次缓存访问仍检查 tasks.read；账号、会话、成员与角色沿用约 1.5 秒的复验节奏。runs.read 变化使用不同键，不能复用含子运行信息的快照。缓存有效期之外仍有数据库与调度延迟，不宣称逐 Token 延迟 SLA。

已有账号的身份解析改成先做新鲜查询，仅在确实没有映射时执行原有原子创建。避免每次 API 访问、每次 SSE 复验都对已存在用户执行冲突 INSERT 和 commit；没有缓存身份或权限。停用账号仍在下一次复验被拒绝。

主要代码：PlatformApp.vue、workspaceCatalog.ts、pageLoading.ts、WorkspacePage.vue、TaskWorkspace.vue、app/services/task_stream.py、snapshot_cache.py、app/api/auth.py、任务详情及应用生命周期。

## 前后对比

本机专用隔离库为 begin_agent_step16_20261106，包含 242 个 Agent、160 个工具、60 个 Skill、1 个合成模型配置、221 条授权目录记录。两个已发布 Agent 位于候选末页，防止仅第一页检查掩盖回归。没有读取真实模型密钥，不调用供应商或外部 MCP。

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 登录入口 JS（原始字节） | 547177 | 91487（降低 83.28%） |
| 概览 JS（本轮浏览器解码字节） | 547177 | 107678（入口＋工作区分包） |
| 全部 JS 总量 | 547177 | 552896 |
| 最大单块 JS | 547177 | 300735 |
| 概览刷新 API 请求 | 17 | 3（auth/config、me、overview） |
| 300 次快照读取 SQL | 1800 | 50（降低 97.22%） |
| 快照读取中位耗时 | 58.471ms | 12.539ms |
| 快照读取 P95 | 76.037ms | 17.584ms |

完整 JS 因拆分辅助代码略增，实际入口和概览下载明显减少；Markdown 与高亮在任务、聊天、运行详情需要时再下载。最大分块约 301kB，构建不再出现超过 500kB 的提示。浏览器概览可见耗时观察值分别为 95ms 和 42ms；前一次入口命中浏览器缓存，后一次加载了新入口，两者缓存条件不同，不用这两个数计算提速比例，也不作为冷启动或生产延迟保证。

SQL 与读取耗时来自同一隔离记录、30 个并发观看者、10 轮读取的微基准，包含事务租户设置和快照 SQL，**不包含 HTTP 鉴权复验**。单做字段投影时为 1500 条 SQL；合并读取后为 50 条。只读脚本 `python -m scripts.benchmark_task_stream` 支持指定 tenant-code、task-code、viewers、rounds、mode 和 output，不创建任务、不触发模型。复现需显式选择隔离数据库中的非终态任务。

另做真实 HTTP 验证：30 个观看者持有效密码会话同时连接 SSE，8 次合成状态更新均送达，所有观看者收到最终内容。首帧中位约 94ms、P95 约 105ms；该本机受控负载不代表生产容量上限。SQL 微基准与带鉴权 HTTP 验证分别记录，没有混用口径。

## 限制和后续

本轮是前端启动与读取路径优化，没有增加 Redis 或事件总线。快照复用只在单 API 进程内有效；不同任务或不同 API 实例不共享，每个连接仍要复验权限。候选编辑器保留全目录行为，尚未引入虚拟列表或远程搜索；超长会话、更多不同任务、高并发大文件、生产数据库与目标 Linux/Python 3.12/PostgreSQL 16 仍需专项验证。不能把 30 个本机观看者的结果作为生产吞吐承诺。
