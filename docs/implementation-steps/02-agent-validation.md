# 第二步：Agent 版本对比与测试结果

状态：已完成。

## 验收标准

- 版本页可选择两个不可变版本，对比模型、提示词、模型参数、执行边界、工具、Skill、MCP 与子 Agent；明确显示差异，不改写版本数据。
- 测试页可选择发布版本运行固定用例，显示每个用例最近一次任务的状态、版本与断言结果，并可跳到真实任务。
- 用例编辑不覆盖历史测试，结果反映执行时固定的期望文本；无任务读取权限不返回测试任务信息。
- 跨租户查询仍返回 404，调试与版本发布权限规则保持不变。

## 本步结果

- 新增结构化版本对比组件，比较提示词、模型配置/快照、模型参数、执行边界、工具、Skill、MCP 与子 Agent；对象字段顺序不造成假差异。保持已发布版本只读。
- 用例列表接口增加 `latest_execution`：只返回最近测试任务的编码、固定版本、状态、时间和断言结果；不返回模型正文或密钥。无 `tasks.read` 时为空。
- 测试页支持选择发布历史版本，运行时传入 `version_code`；最近结果可打开真实任务。用例期望变更不改写历史任务的断言或执行版本。
- 主要代码：`web/src/components/VersionComparison.vue`、`AgentEditor.vue`、`app/api/workspace.py`。

## 验证与证据

- 本步 `tests/test_workspace.py`：10 passed，增加编辑用例后仍保留原期望/执行版本的断言。前端新增结构化比较与历史版本传递测试。
- 本步前端 check：33 项功能测试、6 项 UI 规则测试、类型检查和构建通过；ruff 通过。
- Chromium 实际选择最早历史版本运行用例，Task 固定版本与选择值相同；经真实队列和 Runtime（隔离模拟模型）完成后，列表显示断言通过，固定版本保持不变。
- 版本对比和用例结果两种状态，各完成六种视口，共 12 组几何/截图。长对比内容在表格内部滚动，没有撑宽页面。
- 证据：`output/playwright/implementation-step-02/` 下 `queued-case.json`、`result-check.json`、`geometry.json` 与截图。
- 本地 API 已更新，无数据库迁移，原账号与模型数据保留。

固定用例采用“输出包含期望文本”的确定性断言，不冒充复杂评测体系；本步展示最近一次执行，完整历史仍可在任务/运行记录追溯。下一步补齐工具启停、分组和资源读取。
