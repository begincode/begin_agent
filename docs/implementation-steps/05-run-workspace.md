# 第五步 运行记录与详情

状态：已完成。对应原型运行记录中的任务、Agent、耗时、Token 和执行追踪。

## 实现结果

- `GET /api/v1/runs` 增加 `task_code`、`agent_code`、`days`（0 为全部，1–90 为北京时间日期窗口）和 `root_only`。保留搜索、状态和分页，并按创建时间与编码稳定排序。
- 列表返回任务/Agent 名称、轮次、父/根运行、耗时、步骤数、模型调用数、已上报 Token 和未上报调用数；不返回原始输入输出或租约令牌。步骤用量批量读取。
- 任务名称与标题搜索要求 `tasks.read`，Agent 名称与名称搜索要求 `agents.read`；运行查询仍要求 `runs.read`。无对应名称读取权限时字段为空，不通过名称搜索泄露匹配结果。
- 运行详情保留既有步骤与消息，补充同口径摘要、父/根运行入口、步骤类型与成功/失败筛选。执行中约 1.8 秒短轮询，结束/离开页面停止；错误明确提示并可手工重试，旧响应不能覆盖当前请求。
- 代码：`app/services/execution.py`、`app/api/workspace.py`、`app/api/platform.py`、`RunInspector.vue`、`WorkspacePage.vue`。
