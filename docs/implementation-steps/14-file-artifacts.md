# 第十四步 文件产物与私有对象存储

日期：2026-11-06。状态：已完成。规格见 [文件产物需求](../specs/feature-file-artifacts.md)，验收映射见 [验证报告](../specs/feature-file-artifacts-verification.md)。

## 使用入口与实现

成功任务的“任务产物”页可选择并追加文件。需要当前租户可写、tasks.read / tasks.create，以及任务所有者或 tasks.manage。文件标记“人工上传”，绑定任务当前成功轮次的根 Run；不会伪装成模型输出，也不会自动进入模型上下文。已存文件和文本产物继续保留，不能覆盖或删除历史。

文件卡片显示原始文件名（经安全规范化）、字节大小、SHA-256、上传人、来源 Run 和生成轮次。列表每页 20 条，支持加载更多；没有 runs.read 的账号可读文件但不显示 Run 链接。上传失败保留所选文件及同一重试标识，上传期间禁用重复提交。文件下载使用当前应用前缀及租户请求头，等待服务端鉴权和完整性检查后以附件保存。文本复制与 Markdown 下载继续使用原流程。

| API | 行为 |
|---|---|
| GET `/api/v1/tasks/{code}/artifacts?limit=20&offset=0` | 有界分页、总数和服务器文件上限 |
| POST `/api/v1/tasks/{code}/artifacts?file_name=...` | 原始二进制请求体；必需 UUID 格式 Idempotency-Key；追加文件 |
| GET `/api/v1/tasks/{code}/artifacts/{artifact}/download` | 任务读取鉴权；校验后返回附件与 X-Artifact-SHA256 |

默认单文件 20 MiB，可配置至最多 100 MiB，拒绝空文件；浏览器验收环境特意将上限设为 2 MiB 以验证超限状态。实际接收按请求片段计数，不信任 Content-Length，不使用整请求缓冲；临时文件中转，限制接收时间 120 秒。下载也通过临时文件校验字节数和 SHA-256，内容不正确时返回错误，不发送损坏文件。

存储提供私有本地目录与 S3 兼容后端。默认目录为持久数据目录下 objects/；S3 使用官方 Boto3 SDK、SigV4、私有桶和条件写入。对象键固定为 tenant/{tenantCode}/task/{taskCode}/{artifactCode}，每次全新编码，文件名不决定路径。本地对象原子发布且不覆盖已有对象；S3 配置和对象引用不返回浏览器，S3 客户端连接池在操作后关闭。具体配置、备份、多实例与补偿说明见 [运行说明](../pms-sso-onboarding.md#文件产物与私有对象存储第十四步)。

上传完成存储后再复验会话、权限、租户状态和任务轮次，并在任务行锁内检查重试标识。相同内容与名称重试返回已有记录，不同内容冲突。数据库写入失败、状态变化、会话撤销与正常取消会删除未挂接对象；存储线程退出前不关闭临时文件。数据库提交回执不明时先核对记录，无法核对则保留对象供后续清查，避免删掉已成功提交的文件。

复用 `task_artifact.content` JSONB 保存私有引用和元数据，无数据库迁移；原有不可变触发器继续生效。`artifact_public` 对所有文件响应统一隐藏存储位置和重试键。主要代码为 `app/services/object_storage.py`、`app/services/artifacts.py`、`app/api/artifacts.py`、任务详情及 `TaskArtifacts.vue`。

## 保留边界

当前交付为人工上传的文件产物。模型/外部工具自动生成文件、输入附件解析、内嵌预览、分片与断点续传、自动孤儿对象回收不属于本步。对象与数据库无跨系统事务，强制终止及网络回执不明仍可能留下孤儿对象；需按运行说明核对处理。更换历史目录/桶需要单独迁移设计。

没有可用远程桶配置，本次未验证真实云桶、目标 Linux 环境或高并发大文件负载；这些仍是后续联调与部署验收事项。
