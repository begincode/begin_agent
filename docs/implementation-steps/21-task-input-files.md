# 第21步：任务参考附件

日期：2026-11-06。用户授权连续完善第二十至二十五步，范围见[计划](../specs/feature-steps-20-25.md)。

## 功能

任务创建表单支持最多三个 UTF-8 txt/md/csv/json 文件，单个 32KiB，文本合计 30000 字符。服务端验证 Base64、编码、控制字符、扩展名、JSON 格式和 CSV 行列边界，规范化文件名。原始字节、SHA256、解析文本随任务 input 保存，不需要数据库迁移；幂等重试核对附件内容。普通响应仅含附件名称、大小、摘要，不返回原文或 Base64。

执行器从任务固定快照加入参考材料，明确标记其为数据，不作为系统指令。后续对话继续使用原附件；上下文与 Token 预算仍生效。前端不执行原始 HTML；下载由 tasks.read 与租户校验保护，通过附件响应返回原字节和哈希。没有 PDF/Office/图片、压缩包或可执行文件解析。
