# 侧栏目录折叠与滚动优化

日期：2026-10-30。用户要求目录支持折叠，并改善左侧滚动条外观。

## 实现与验收标准

- 工作空间、能力资源、组织管理按有权限的菜单显示分组，每组可点击或使用键盘展开/收起，提供 `aria-expanded`、`aria-controls`。
- 本地记忆分组状态，刷新恢复；无效存储内容回退为展开。切换到其他菜单入口时展开目标分组。
- 整体图标栏模式与手机窄屏保持全部已授权图标可见，避免分组标题隐藏后无法访问被折叠入口。
- 左侧滚动条改为 6px 深色圆角滑块、透明轨道，悬停/键盘聚焦时增强显示，Firefox 使用原生细滚动条后备样式；保留滚动和底部菜单访问。
- 控件继续使用共享的 40px 高度和 8px 圆角。

## 本次验证

- `npm --prefix web run check`：53 项功能测试、6 项 UI 规则测试、类型检查与生产构建通过。新增回归覆盖偏好恢复、无效存储回退及目标分组自动展开。
- 独立 Chromium 实测 Enter 折叠、刷新恢复、图标栏入口、自动展开目标组和滚动到底部。实际滑块宽度 6px，轨道透明。
- 展开、分组折叠、整体图标栏三种状态，各覆盖 320×800、390×844、768×1024、1280×720、844×390、390×360，共 18 组截图与几何数据。没有页面溢出或控件尺寸偏差。
- 证据：`output/playwright/sidebar-navigation/geometry.json`、`interactions.json`、截图与 `web-check.log`。浏览器使用隔离服务，业务数据未写入实际库。
- 本次仅修改前端，未执行后端测试；API/Worker 不需要重启，静态产物通过原服务提供。PMS 本地静态运行包同步后与构建产物一致。
