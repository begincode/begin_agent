# 内置用户体系

用户已明确取消 SSO，要求平台自有用户体系。本轮替换前端登录流程与默认认证模式。

- 首次部署由初始化页创建首位平台管理员；旧模型和租户数据保留并关联至该管理员。
- 用户名密码登录，密码使用随机盐 scrypt，服务器会话只保存令牌摘要；HttpOnly Cookie、同源写请求与退出撤销。
- 平台管理员创建用户、启停、重置密码；用户修改自己的密码，修改/重置密码撤销其他会话；不能停用自身或最后一位平台管理员。
- 租户管理员按已有用户名添加成员，使用本平台 user_code 关联；移除前端对 19 位 SSO 用户号的依赖。
- 登录失败共享数据库限流，过期/停用账号返回 401；敏感字段不返回、不入审计。
- 默认为 password 模式；显式 local 仅保留本机开发兼容用途。前端不再展示 SSO 或要求其登记。
