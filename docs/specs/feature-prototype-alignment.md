# 第一版交互原型补齐

用户已明确要求修改，按 `docs/current-ui-review-20261029.md` 和现有 27 页原型补齐，不再次缩减为六个表单页。

## 验收范围

1. 深色可折叠侧边导航、概览、独立列表/新建/配置/详情路由；刷新和后退保留当前页面。
2. 同一 Task 持续对话，每次提交生成独立根 Run；历史消息与 Run 持久化。执行中禁止并发追加轮次，失败输出不作为成功上下文；重试和取消有明确状态。
3. Agent 三步创建、独立基本配置/协作/调试/版本/测试用例页；保存草稿不影响发布版本；回滚只切换当前版本，已提交任务继续使用原版本。调试和固定用例通过真实任务队列运行。
4. 模型、工具分组、MCP、Skill 分别提供列表和配置；MCP 有真实连接检测及工具发现，凭据加密不回显；Skill 提示内容及资源授权随 Agent 版本固定，Runtime 实际使用。未经服务器管理员允许的网络主机不连接。
5. 租户资源的启停与 Agent 授权、成员角色、角色权限、平台用户、审计入口实际连接服务端；权限在 API 验证，前端隐藏按钮不能替代鉴权。不可移除最后管理员。
6. 概览、任务/Agent/运行列表支持查询及状态筛选，显示真实数据；空状态给出明确下一步，不伪造演示结果。
7. 用户已取消 SSO，默认内置账号登录。系统状态页显示账号模式及 PMS 托管/Worker 真实状态；PMS 尚未登记时明确显示本地运行。
8. 数据迁移保留现有模型密钥、Agent、任务。后端完整测试、前端 check、六种规定视口截图/几何检查；部署后保持 `http://127.0.0.1:18029/` 和 Worker 运行。

## 验证重点

租户/RBAC/资源隔离；多轮并发与幂等；版本回滚和草稿不影响历史；Skill/MCP 工具快照；网络与凭据边界；页面深链、表格和聊天响应式；真实模型的最小请求验收与模拟上游测试分开记录。
