## 范围与验收

- POST agents 支持 Idempotency-Key。相同账号、租户、键和规范化内容只创建一个 Agent，并返回原始创建结果；同键不同内容 409。创建和回执同事务，失败不留半成品；相同键并发请求串行核对。
- 原始回执包含创建编码和初始配置 ETag，不用最新条件掩盖并发修改。首次 201、重放 200，并标记响应和审计。未带键的旧客户端仍按原行为创建，不提供重试去重保证。
- 提供当前账号、当前租户的创建结果查询，权限仍要求 agents.manage。查询不到不等于请求一定失败，不自动换键或新建。停用租户禁止重放写入，历史查询只读。
- 向导首次提交前记录请求标识和基本信息；同页失败重试使用同一请求，保留尚未保存的配置。按账号/租户保留本标签页的恢复记录，不存提示词、资源配置、密码或模型密钥。
- 刷新后展示恢复入口，查询或重试原创建请求只找回/创建原 Agent，再进入已有配置页，不把刷新后的默认表单自动写回。未确认结果前不能悄悄开始新的请求。
- 旧配置已被修改时保留第十八步的 412 冲突保护。保护租户/账号隔离、权限、只读、不可变历史与已有凭据。
