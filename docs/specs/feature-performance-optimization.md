# 第十六步：性能优化

日期：2026-11-06。用户授权实现、重新编译启动、浏览器验证和总结文章。

## 本轮范围

1. 按页面异步加载组件，概览不引入运行详情和 Markdown/代码高亮。保留原有高亮语言和渲染安全规则，补齐加载、失败刷新状态；不调高包体告警阈值。
2. 共享候选目录按路由需求读取；概览、普通列表和账号页不预取编辑器所需的全部目录。Agent 配置、协作、新建任务所需候选仍可读取后续分页。页面挂载前等待必要目录，切换租户、退出和过期请求清理旧数据并取消读取；不缓存鉴权结果。
3. SSE 查询只投影实时展示所需字段，避免每轮读取完整 Task 输入/输出和 Run 正式输出。同一 API 进程内，按数据库工厂、租户、任务和 runs.read 查看能力合并正在执行的快照读取，允许最多 250ms 的非终态快照复用。初次连接保持新鲜读取；终态不缓存。
4. 缓存有界（条目、有效期、单条大小），无独立后台轮询；断开一个连接不能取消其他观看者的共享读取；应用停止时清理。tasks.read 每次读取检查，账号/会话/成员/角色仍每 1.5 秒复验，runs.read 变化使用独立数据键，不能互相泄漏。
5. 用同一隔离数据集记录前后包体、概览业务请求与 SQL 快照查询量、受控并发响应时间。提供可复用只读基准脚本，说明本机与负载范围，不把局部结果当作生产吞吐保证。使用合成任务，不调用付费模型或外部 MCP。

## 验收

- 构建前后指标可复查；登录入口 JS 降低至少 50%，概览不拉取工具/授权/候选全集，生产构建不出现单块超过 500kB 的告警。
- 后端测试验证并发合并、过期/终态、缓存边界、权限/租户隔离、撤权和取消；原实时输出/文件/真实联调诊断回归保留。
- 前端测试验证按需目录、后续分页、路由/租户竞态、异步页面加载失败和恢复；全量 check、后端/Ruff 通过。
- 重新启动实际 API/Worker，保留原数据；隔离 Chromium 验证大目录、实时输出/重连、Markdown/下载、错误加载，六视口截图与几何及页面巡检。出现问题修复并重跑受影响检查。
- 输出实现文档、验收报告及独立总结文章，记录尚未验证的目标 Linux 环境和生产负载。
