# 后续运行与任务工作区

用户已授权继续按设计实现，并要求每一步完成后整理总结文章。本轮沿用 `runs.html` 与 `task-detail.html` 原型，依次完成第五、六步；每步验收与文章完成后再进入下一步。

## 第五步 运行记录与详情

- 运行列表展示任务与 Agent 名称、轮次、耗时、实际已上报 Token 和未上报调用，不返回列表不需要的原始输入输出。
- 服务端支持搜索、状态、任务编码、Agent、日期范围和根运行筛选，分页顺序稳定。任务/Agent 名称分别服从对应读取权限，所有查询受租户约束。
- 独立运行详情展示摘要、父/根运行入口、步骤类型与失败筛选。执行中短轮询，结束或离开页面停止；失败可重试刷新，不能被旧请求覆盖。
- 无数据库结构变更。验证真实 PostgreSQL 查询/隔离/权限、前端筛选和轮询、六种规定视口与长内容。隔离模拟模型记录不作为外部模型验证。

## 第六步 任务复用与文本产物

- 成功的普通任务可重新执行最近一轮要求，新增轮次，继续固定原版本并保留成功历史；失败/取消任务继续使用重试入口，测试任务通过用例入口运行。
- 重新执行使用幂等键，拥有者需任务创建权限，任务管理者可管理他人任务；执行中、租户/Agent 停用、超过轮次上限时拒绝。接口自行鉴权，不能仅依赖按钮。
- 对话框支持 Ctrl/Command + Enter 发送，Enter 保留换行；组合输入和禁用状态不能误提交。
- 文本产物展示来源 Run 与版本，支持复制原文及下载 Markdown；复制失败不显示成功，下载只包含原始文本，文件名安全。无产物与非文本状态有明确提示。
- 验证固定版本、历史、幂等和权限，浏览器验证重新执行、快捷键、复制及实际下载内容，覆盖六种规定视口。保留既有数据库和密钥。

## 交付顺序

每步按实现、相关自动测试、前端完整 check、真实浏览器交互与几何截图、交付文档、总结文章的顺序完成。最后运行完整后端检查并更新原端口与本地 PMS 运行包。使用独立验收数据库，不调用付费模型，不执行外部部署。
