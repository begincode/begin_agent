# 第二十至二十五步交付计划

2026-11-06，用户授权连续完成全部后续步骤，沿用独立账号、不接 SSO。每步实现后完整检查、重新编译启动、独立 Chromium 验证并整理实施记录与独立文章。外部环境缺少配置时如实记录未验收，不冒称生产发布。

| 步骤 | 本轮范围 | 验收标准 |
|---|---|---|
| 20 | 本标签页向导完整草稿 | 账号/租户隔离、24 小时有界存储、显式恢复/放弃；恢复基本信息/模型/指令/资源及步骤；不存模型密钥，与创建幂等和条件保存兼容 |
| 21 | 任务文本输入附件 | 有界 UTF-8 文本/Markdown/CSV/JSON 上传、解析校验、任务快照和鉴权下载；模型读取明确标记的参考材料，不执行文件内容 |
| 22 | 执行生成文件 | 显式启用文本导出工具，生成文件通过现有私有对象存储和产物鉴权下载；失败/取消不冒称成功；有大小限制和补偿 |
| 23 | 跨主机心跳与告警 | 数据库 Worker 心跳、当前租户队列告警与事件确认，租户/RBAC 保护；不自动重试任务、不擅自外发通知 |
| 24 | 备份恢复与对象核对 | 独立库完整恢复演练、备份校验清单、只读对象引用核对，默认不删除任何对象 |
| 25 | 部署验收 | 目标环境预检、API/Worker 命令检查模板、部署清单和可重复压力检查；可用环境实测，不可用的 Linux/云桶/MCP/PMS 登记列为环境待办 |

新增外部副作用必须使用显式配置；测试业务写入隔离库，不修改原历史；真实账号、模型密钥和主密钥保留。迁移先备份并核对既有数据，禁止合并 master，不自动提交推送。
