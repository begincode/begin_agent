# 第十四步：文件产物与对象存储

日期：2026-11-06。用户已授权实现、重新编译启动、浏览器验收与总结文章。

## 行为与边界

- 在任务“产物”页追加上传文件，默认单文件上限 20 MiB，可由服务器配置调整（最大 100 MiB）。使用流式请求和临时文件，拒绝空文件及超限请求。
- 任务必须已成功，上传者须是任务创建者或拥有 tasks.manage，并具有 tasks.create、tasks.read；租户停用只读。文件标记人工上传，关联此次成功根 Run，不把文件内容当作模型结果或上下文。
- 文件采用全新实体编码路径 tenant/{tenant}/task/{task}/{artifact}。原文件名只作元数据，不能决定存储路径。保存大小、SHA-256、上传人、来源运行；产物追加且不可变。
- 本地私有对象目录默认位于持久数据目录；可配置 S3 兼容私有桶，使用官方 Boto3 SDK。客户端不能选择桶、后端、对象键或外部 URL。
- 文件经系统登录、当前租户和 tasks.read 鉴权后以附件下载，校验大小和 SHA-256；不公开目录、不提供绕过鉴权的预签名 URL、不执行 HTML/SVG。下载不依赖 runs.read。
- 上传后复验身份与任务状态；数据库提交失败补偿删除本次对象。上传重试键相同且内容相同返回已有产物，不覆盖；键相同而内容不同返回冲突。对象与数据库不能原子提交，进程崩溃可能留下孤儿对象，须在运维文档明确说明。
- 文件列表服务端分页，现有 JSONB 文本产物继续复制和下载。新增内容复用既有 JSONB，不修改表结构或历史记录。
- 没有真实桶配置时以本地对象目录和隔离 S3 协议服务验收，不宣称云桶联调通过。不恢复 SSO，不登记远程 PMS。

## 验收

1. API/存储测试：二进制往返、中文/恶意文件名、空文件/超限、校验失败/对象丢失、跨租户/无权限/非所有者、停用只读、重试幂等、失败补偿、本地路径穿越/符号链接、S3 SDK 请求/错误。
2. 前端完整 check：选择/上传/重试/分页/下载反馈、权限与只读状态；上传错误保留选中文件，重复点击受控。
3. 重新构建启动实际服务；隔离数据库的 Chromium 验收上传、刷新、逐字节下载、错误、权限和六种规定视口（截图+几何）；实际数据库只做就绪/登录页检查。
4. 整理实现文档、验证报告及独立总结文章；保留未验证事项。
