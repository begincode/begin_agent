# 前端变更必须遵守的规则

本目录所有变更（Vue、TypeScript、CSS、依赖、构建及校验脚本）必须遵守 [前端开发规范](../docs/frontend-standards.md)。父级和用户提供的规则继续适用。

1. 修改前阅读前端开发规范，复用共享控件变量；单行控件统一 40px 高、8px 圆角。禁止在组件、媒体查询或内联样式中随意改写控件尺寸。
2. 每次前端修改后，必须执行 `npm --prefix web run check` 或 `make web-check`。校验失败必须修复，不得通过跳过、删除或削弱检查来交付。
3. 涉及界面、布局、样式、控件状态或交互的修改，还必须在真实浏览器验收：桌面与手机、同排控件对齐、Logo 居中、焦点/禁用/错误/加载状态、长内容及页面溢出。响应式修改必须覆盖规范中的六种视口。
4. 浏览器验收需要读取实际几何尺寸和截图，不能只阅读 CSS 或以构建成功代替。人工浏览器验收尚未接入 CI；自动样式检查不等于真实布局验证通过。
5. 交付时说明改动、执行的校验、检查视口和结果；UI 修改保留截图。新增或修改了影响检查结论的代码后，须重跑受影响检查。没有执行的检查必须明确写出，不得引用旧结果冒充本次通过。
6. 不改变规范例外或增加新控件尺寸档位来绕过检查。确需新的设计规格时，同时更新规范、共享变量和校验规则，并验证旧场景不回归。
